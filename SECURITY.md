# Security Policy

Nôs Raiz stores personal family data, including information about living people. Security reports are taken seriously.

## Supported versions

The project is pre-release. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) (repository **Security** tab → **Report a vulnerability**) with:

- A description of the issue and its impact
- Steps to reproduce
- Any suggested fix

You can expect an acknowledgement within 7 days.
